## Оперативная память

- Можно редактировать файл напрямую
- Изменения теряются после перезагрузки сервера, и все откатывается до изначального прописанного состояния

## Хранение в файле

- Можно видеть и редактировать файл напрямую
- Изменения сохраняются
- Возможен _race condition_

## Где еще можно хранить?

SQL / NoSQL БД

## Минусы внешнего сервиса

При одновременном обращении одно из изменений может не быть записано. В идеале, надо блокировать каждое обращение на стороне внешнего сервиса.
